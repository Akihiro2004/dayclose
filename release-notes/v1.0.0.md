# Dayclose 1.0.0

A quieter way to finish your day. Dayclose helps you review the things that matter before shutting down your Windows computer.

## Reminders that fit your routine

- Add, edit, and delete reminders with titles, notes, and Active, Paused, or Completed status.
- Set all-day reminders or daily time windows, including overnight ranges such as 22:00–02:00.
- Review only active reminders within their time window when you use the dedicated **Review & Shut Down** shortcut.
- Mark reminders completed and reactivate them when needed.
- Find reminders by title or notes, filter by status, and choose your preferred sorting order.

## A focused interface

- A monochrome interface with Light, dark-gray Dark, and System appearance modes.
- A dedicated Settings panel for appearance, library preferences, data, and updates.
- Optional notes previews and a default status filter for new manager windows.

## Local data and backups

- Reminders and preferences are saved locally, with no account required.
- Create reminder database backups and open the data folder from Settings.
- Your reminders and settings are preserved when updating or reinstalling the app.

## Updates inside Dayclose

- Background update checks when the reminder manager starts.
- Update notices, release notes, download progress, and cancellation under **Settings → Updates**.
- SHA-256 verification before installation.
- An **Install and restart** flow that backs up reminders, closes Dayclose, installs the update, and reopens the app with the same data folder.

## Install

Download and run **Dayclose-Setup-1.0.0.exe**. Python is not required. The installer adds Start menu shortcuts, optional desktop shortcuts, and an uninstall entry in Windows Settings.

Already using an earlier Dayclose build? Install this build once to enable in-app updates. Future updates will appear when a higher stable version is published.

## Verification and current limits

- 28 automated tests passed.
- Local installation, the actual update helper, automatic app reopening, and uninstall were verified in an isolated installation. Reminder contents and settings survived the update.
- The installer is unsigned, so Windows may show an unknown-publisher or SmartScreen prompt.
- Actual computer power-off and installation on a clean Windows machine have not been verified.
- Windows' normal Shut down button bypasses Dayclose. Use the dedicated shortcut to review reminders first.
